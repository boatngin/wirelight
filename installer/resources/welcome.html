Welcome to Wirelight

A small menu bar app for connecting to WireGuard® peers on macOS.

This installer adds:

  • Wirelight.app in /Applications
  • A privileged helper (wgbar-helper) that runs as a LaunchDaemon and sets up the tunnel interface, routes and DNS
  • The wgbarctl command line tool in /usr/local/bin

Before you install, make sure the WireGuard tools are installed with Homebrew:

brew install wireguard-tools wireguard-go
